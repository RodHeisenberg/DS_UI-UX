UX LAB
================================

COMO ABRIR LOCALMENTE
1. Descompacte todos os arquivos na mesma pasta.
2. Abra o arquivo index.html no Chrome, Edge ou Firefox.
3. Não é necessário instalar aplicativos ou rodar um servidor.

OBSERVAÇÕES
- Não há login, acompanhamento remoto ou correção automática das respostas discursivas.
- As respostas são salvas somente no armazenamento local do próprio navegador.
- A atividade não envia dados para servidores externos.
- Para revisar o trabalho do grupo, o professor deve receber o PDF/TXT.
- Abrir links para sites de terceiros depende de conexão à internet.
