UX LAB | AULA 03 | SENAI | T01 DF
================================

CONTEÚDO DO PACOTE
- index.html          Entrada visual da aula
- demonstracao.html   Exemplos interativos para o docente usar durante a explicação
- atividade.html      Atividade dos alunos de 40 minutos
- styles.css          Estilos visuais e responsividade
- app.js              Interações, quiz, armazenamento local e relatório
- favicon.svg         Ícone do projeto

COMO ABRIR LOCALMENTE
1. Descompacte todos os arquivos na mesma pasta.
2. Abra o arquivo index.html no Chrome, Edge ou Firefox.
3. Não é necessário instalar aplicativos ou rodar um servidor.

COMO PUBLICAR NO GITHUB PAGES
1. Crie um repositório público no GitHub (ex.: senai-ux-lab-aula03).
2. Envie o CONTEÚDO da pasta para a raiz do repositório.
3. Abra Settings > Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Escolha branch main e pasta /(root), e salve.
6. Use o endereço publicado pelo GitHub Pages, geralmente:
   https://SEU_USUARIO.github.io/senai-ux-lab-aula03/

ORIENTAÇÃO PARA O DOCENTE
- Comece por index.html.
- Use demonstracao.html durante a explicação: campos confusos/claros,
  UI x UX, critérios e os 4 modelos de layout.
- Quando iniciar a atividade, compartilhe o link de atividade.html.
- A atividade segue o slide 04: análise de TRÊS sites ou apps,
  respondendo QUATRO perguntas em cada um.
- Tempo: 5 min escolha, 24 min análise, 6 min quiz, 5 min entrega.
- O quiz de 6 questões é autocorrigível e serve como reforço formativo.
- As notas de usabilidade de 1 a 5 são impressões dos alunos, não dados
  obtidos em testes formais; a análise de acessibilidade é exploratória.
- Para entrega, use Imprimir / salvar em PDF ou Baixar relatório TXT.

OBSERVAÇÕES
- Não há login, acompanhamento remoto ou correção automática das respostas discursivas.
- As respostas são salvas somente no armazenamento local do próprio navegador.
- A atividade não envia dados para servidores externos.
- Para revisar o trabalho do grupo, o professor deve receber o PDF/TXT.
- Abrir links para sites de terceiros depende de conexão à internet.
